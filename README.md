# Deepika Sharma Makeup Studio & Academy - Salon ERP

React + Vite + Tailwind. Backend: Google Apps Script + Drive + Sheets.

- Local run: `npm install` then `npm run dev`
- Setup guide (Hinglish): `SETUP_GUIDE_HINGLISH.md`
- Backend code: `apps-script/Code.gs`
- URL / key config: `src/config.ts`


## Updated database and media setup
See [`SUPABASE_SETUP_HINGLISH.md`](./SUPABASE_SETUP_HINGLISH.md) for Supabase Auth, RLS, Booking/Daily Customer persistence, and Google Drive media picker setup. Run `supabase/schema.sql` before logging in.
